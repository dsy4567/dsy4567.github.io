}

## 换行与空格

单个换行不会变成 `<br>`：这两行在源码里分了行
渲染后仍是同一段。

行尾两个空格
会变成硬换行。

行尾一个反斜杠\
同样会变成硬换行。

需要排版缩进时可以用实体：&emsp;&emsp;这就是两个全角空格的效果。

也可以直接写 <br /> 标签来换行。

## 已知不支持

- 脚注：`[^1]` 与 `[^1]: 说明` 会被 marked 当成引用式链接的写法，渲染成一条链接，而不是脚注。
- 高亮 `==文本==`：不是标准 Markdown，需要额外插件，本站没装。
- 定义列表：`术语` 换行接 `: 解释` 的写法没有任何效果。
- 任务列表以外的扩展：复选框只有浏览器默认样式，本站没有额外的 CSS。
